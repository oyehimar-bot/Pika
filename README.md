# 🐹 Pika

> Modern, local-first inventory & stock management for SMEs.

![Pika Logo](./public/pika-logo.png)

## Features

- 📊 **Dashboard & Metrics** — Real-time sales, inventory value, fast-moving items, low-stock warnings
- 📦 **Inventory & Batch Management** — FIFO costing, batch IDs, automated expiry tracking
- 🛒 **Point of Sale (POS)** — 100% offline-ready, barcode scanner, thermal/digital receipts
- 🔒 **Audit Trail & Staff Security** — 4-digit PIN auth, immutable logging
- 💾 **Data Ownership** — Automated CSV/JSON/SQLite exports, zero data loss

## Tech Stack

- **Frontend:** React + TypeScript + Vite
- **Styling:** Tailwind CSS + Lucide Icons
- **Storage:** IndexedDB via Dexie.js (local-first)
- **Architecture:** Offline-first with background sync capabilities

## Getting Started

```bash
npm install
npm run dev
```
